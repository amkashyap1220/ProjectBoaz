# Security policy

Project Boaz handles brokerage API keys, so I take security reports seriously.

## Reporting a vulnerability

Please report privately using GitHub's **Report a vulnerability** button on the Security tab of this repository. Do not open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. I'll reply as soon as I can, and I'll release a fix before any details are made public.

## Supported versions

I only release security fixes for the latest version.
